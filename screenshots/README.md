# UX-Shield interactive screenshot demo

Open `index.html` in a browser. No installation, server, build step or internet connection is required.

- Choose GetYourGuide, Booking.com room selection, or Booking.com search results.
- On GetYourGuide, drag across the screenshot or use the range slider. The slider supports the arrow, Home and End keys.
- Use Before and After to view a complete capture.
- Booking.com uses side-by-side images (stacked on mobile) because the original captures have different scroll positions. Images retain their original proportions.
- Open the original images using the links below the viewer to inspect small details.

To share, send `ux-shield-demo.zip`. Recipients should extract it and open `index.html`. Alternatively, host `index.html` together with the `Booking.com` and `getyourguide-options` folders on a static website, keeping the same relative paths.

The demo displays the six supplied PNGs without editing them. It does not run the extension, simulate a live booking, or establish that booking interactions pass functional tests. Captions describe what is visible in these captures. All styles and JavaScript are included locally; no dependencies, remote assets, analytics or network requests are required. The project link opens GitHub only when clicked.

This page is separate from the shipped extension; no extension reload is required.
